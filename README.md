# 真相ガチャ

都市伝説と陰謀論を集めて、黒塗りを剥がしていく収集ガチャ。
バトルも育成の口実もなく、ガチャを引くこと自体が目的のゲーム。トーンは皮肉・風刺。

- 本体：`index.html`（HTML / CSS / JS をすべて含む単一ファイル）
- 遊び方：`index.html` をブラウザで直接開く（サーバー不要）
- 管理：このリポジトリに一本化（claude.ai の公開ページは廃止済み）
- 仕様：[docs/SPEC.md](docs/SPEC.md) ／ 設計判断：[docs/DESIGN.md](docs/DESIGN.md) ／ 公開・運用手順：[docs/SETUP.md](docs/SETUP.md)
- Firestoreのルール：[firebase/firestore.rules](firebase/firestore.rules)

## コアループ

1. 疑念ptで封筒（ガチャ）を引く
2. 同じネタを引くたびに黒塗りが1段剥がれる（全5段。5段目が「真相」）
3. 真相到達後に同じネタを引くと「目撃証言」が手に入る
4. ガチャで「証拠」が貯まり、調査室の設備を強化する
5. 進捗はシェアできるが、真相（Lv.5）の中身は共有されない

## ネタ（29件）

| 区分 | 件数 | 内容 |
|---|---|---|
| 都市伝説 | 12 | 8番出口の老人、きさらぎ駅、口裂け女、花子さん、くねくね ほか |
| 陰謀論 | 12 | 月面着陸捏造説、エリア51、電球の寿命カルテル、MKウルトラ ほか |
| 深層ファイル | 5 | ランクで解禁（RANK 6 / 9 / 12 / 15 / 18） |
| 機密区分外 | 1 | 黒塗りの合計段数で自動開示（35 / 65 / 95 / 120 / 145） |

- 各ネタは5段：噂 → 発生時期 → 詳細 → 信じてる人の特徴 → 真相
- 実在の出来事を扱う「事実」判定のネタ（電球カルテル、MKウルトラ、エリア51、トンキン湾事件、タバコ業界、鳥は実在しない）は、Wikipedia等で裏取り済み
- 陰謀論には必ず「判定：根拠なし」などの判子を表示する（切り取られて誤情報として広まるのを防ぐため）

## ガチャ

| 種類 | 費用 | 解放 |
|---|---|---|
| 1回 | 10pt | 最初から |
| 5連 | 45pt | 最初から |
| 10連 | 90pt | RANK 5 |
| 100連 | 850pt | RANK 11 |

- 本日のウワサ：毎朝「郵便受け」に届く、日付で決まる1件（全員共通）。差出人は不明で、連続日数と時刻で投函の描写が変わる。読むと黒塗りが1段剥がれる（1日1回）
- 5連以上は、必ず1段以上剥がれる保証付き
- 10連・100連は演出なしで結果をまとめて表示

### 排出の重み

- レアリティ：並 1 ／ 稀 0.5 ／ 禁 0.22
- 進み具合：未発見 ×1 ／ 調査中（Lv1〜4）×1.6 ／ 真相到達 ×0.35
- ランクと設備で稀・禁の倍率が上がる
- 天井：未発見の資料が出ない回数が上限に達すると、未発見の資料が確定（初期30回、ランクと設備で短縮、最短5回）
- 二重解除：一定確率で黒塗りが2段剥がれる

## 一般人モード（入門版）と面接

- 初めて開いた人は一般人として始まる。ptも放置も無く、届いた封筒を開いて記録を読むだけの超ライト版
- 対象は12件（都市伝説6・陰謀論6）。各Lv.3まで読め、全36断片で完走。Lv.4〜5は黒塗りのまま
- 開封を続けるとメモや異常イベントが段階的に開く（3 / 6 / 10 / 15 / 18 / 24 / 30 / 36断片）。第六文書課の気配を小出しにし、10で診断、18で異常記録、24で面接招待、36で完全記録
- 24断片以降に「調査員になる」が開く。面接（志望動機・守秘義務・信じる側か疑う側か）を経て採用され、調査員番号・タイプ・配属が付き、読んだ分は本編に引き継がれる
- 一般人編にも途中経過、閲覧傾向診断、異常記録、観察継続、完全記録と複数のシェア契機を置く。プレイヤーごとに観察番号が付き、共有URL経由で来た人には転送元の観察番号が残る
- 既存のプレイヤー（ガチャ済み・案内表示済み）は、自動で調査員として扱う
- 状態：`role`（`agent` なら調査員）、`lite`（拾った段数）、`assign`、`agentNo`

## 調査室（育成）

ガチャで貯まる「証拠」で設備を強化する。疑念ptはガチャ専用。

- 証拠の入手：新規ファイル 3 ／ 黒塗り解除 1（二重解除 +1）／ 目撃証言 並2・稀5・禁15

| 設備 | 効果 | 最大 |
|---|---|---|
| 盗聴ラジオ | 放置効率 +10%/段 | 20段 |
| 留守番電話 | 留守中に貯まる上限 +1時間/段（基本2時間） | 10段 |
| 古い虫眼鏡 | 嗅ぎ回りの1日上限 +200pt/段 | 10段 |
| 書き込みだらけの地図 | 天井 −1回/段 | 5段 |
| 黒塗り除去液 | 二重解除 +1%/段 | 10段 |
| 情報屋の名刺 | 稀 +3%・禁 +5%/段 | 10段 |

## 疑念ptの入手

- 放置：5秒ごとに1pt × 放置倍率（ランク × 盗聴ラジオ）。2時台（丑三つ時）は2倍
- 留守中：1分ごとに1pt × 放置倍率（上限は留守番電話で決まる）
- 嗅ぎ回る：1日400ptまで1タップ+2、800ptまで+1、以降0（虫眼鏡で上限拡大）。1秒12回を超える連打は無視
- 連続調査ボーナス：その日初めて開くと 20 + 10 × 連続日数（最大7日分）
- 本日の任務：4件、0時リセット
- 重複（真相到達済み）：+3pt

## 収集・ソーシャル要素

- シリーズと称号：7シリーズ。シリーズの全ネタを集めると称号、全ネタ真相到達で「（真）」
- 目撃証言：時刻・場所・証言者・一言の組み合わせで約9万通り。並・稀・禁あり
- 信者度診断：収集傾向から6タイプを判定
- シェア：進捗の色マス、黒塗りカード画像（canvas生成）、診断結果。Lv.5の中身は含めない
- 今日の調査員：同じ日に遊んでいる人数と、解読量の順位を表示

## 演出

- 封筒を開ける演出（揺れる → 開く → 資料がせり上がる → 黒塗りが剥がれる）。高速モードあり
- 稀は琥珀色、禁は赤く脈打つ封筒で、開ける前から分かる
- 22時〜5時は画面が赤みを帯びて照明がちらつく。2時台は丑三つ時
- ホームに匿名掲示板風の「調査スレ」。まれに名前もIDもない書き込みが混ざる
- 都市伝説は罫線ノートの聞き取りメモ、陰謀論は綴じ穴付きの機密文書として描き分け

## 保存

- `localStorage`（キー：`shinso_gacha_state_v1`）。進捗はブラウザごとに保存される
- アカウント保存と「今日の調査員」は Firebase（匿名認証＋Google連携、Firestore）。`file://` で開いた場合は無効で、端末内保存だけで動く
- 設計は [docs/SPEC.md](docs/SPEC.md) §6.3

## 技術メモ

- フォント：Shippori Mincho / Zen Kaku Gothic New / Courier Prime / Yomogi（Google Fonts）
- 日本語の改行：対応ブラウザは `word-break: auto-phrase`、それ以外は BudouX（jsDelivr から読み込み、失敗時は簡易ルール）
- `prefers-reduced-motion` で演出を停止

## 既知の課題

- 終盤は証拠が余り、全設備が中盤で上限に達する
- 証言は組み合わせ生成のため、数百件を超えると文面の重複が目立つ
- Firebase 側の設定（匿名認証、Googleログイン、ルール、承認済みドメイン）が未完了だと、クラウド保存は動かない
- 一般公開する場合は、提供割合の表示ルールと、実在の出来事に関する記述の再確認が必要
