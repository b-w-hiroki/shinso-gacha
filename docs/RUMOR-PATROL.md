# 噂を追う巡回と育成

- 最初から4地点を巡回。袋から候補を消費し、同じ地点を連続させない。追跡対象の地点×3、未発見の地点×2で袋内の順番を重みづけする。同じ場所だけに固定するものではない。
- 抽選は次の観測に移るときに確定。タップ、育成、リロード、追跡対象変更では保持結果を引き直さない。
- 異変の総率は初期5%、異常感度Lv.0–14、1段階0.5ポイント、上限12%。異変内の種類は未発見×2、追跡中の噂に関連する種類×1.6。総率には影響しない。
- 平常4件ごとに最大12段階の無線・課内の手がかり。発見扱いや追加報酬にはしない。
- 対処した異変の文脈を最大5分保持。課内へ戻ったときに人物への干渉につなぐ。休息で解除し、同じイベントを繰り返さない。

## 観測と調査室

観測画面の3つ目の操作を「機材・育成」に変更。調査室では現在地点・追跡対象・感度を表示して育成を開き、「観測へ戻る」で保持中の同じ画面へ戻る。観測設定は育成後に調査室から開く。演出軽減は従来どおりメニューから常時利用可能。

観測枠は画面の使用可能な高さに合わせて固定。各画像は縦横比を維持し、余白を暗くして全体を収める。画像が変わっても枠と下の操作列の位置を保つ。短い横画面では縮小しすぎずスクロールを許す。

モデルテストは移行・費用・上限・抽選率・袋の巡回・引き直し防止。ブラウザテストは旧保存からの二重返金防止、全地点×4状態×3サイズの枠固定、観測↔育成、課内への干渉を確認する。恐怖や長期的な楽しさの実証を意味しない。
