# 遊びやすさ・恐怖演出の厳格レビュー

対象: PR59 時点の調査員編。表示が崩れないことだけで、遊びやすさや恐怖を合格にしない。

| 優先度 | 問題 | 対応・検証条件 |
|---|---|---|
| 最優先 | 観測以外への道はあるが、移動する理由がない | 下部の名前を観測・封筒・資料へ具体化。メニューに行動へ直結する手引き。未読観測資料へ既存の一文から移動できる |
| 最優先 | 有効なタップと空振りの意味が伝わらない | 有効接触は局所反応と短い言葉、連続空振りは無反応の言葉。回数・HP・コンボは表示しない |
| 高 | 異変を見つけられない人に逃げ道が分かりにくい | 手引きから既存の場所選択へ。正常時は対処を出さず、未発見の名前・画像・正解座標は明かさない |
| 高 | 記録が画像一覧で終わり、読む目的が弱い | 16記録に固有の所見。平常との比較を維持し、資料から関連する同僚へ直接尋ねられる |
| 高 | 会話が観測と無関係な台詞集になっている | 取得・閲覧した記録だけに対応する証言。話したことを保存し、資料に食い違いを追記。再読で報酬・回復を稼げない |
| 高 | 恐怖の段階差が文言と枠色だけで弱い | 後期侵食は画面外の縁に人影が残る。静止・非遮断・控えめな表現。軽減設定では非表示、休息で消える |
| 高 | 資料や会話へ離れたときの休息状態が曖昧 | 資料閲覧で回線を閉じる。自動再開せず「観測を再開」で戻れる。獲得資料とptは保持 |
| 中 | 次の育成目標・重複記録の用途が見つけにくい | 手引きに実際の所持・解放条件から次の目標を表示。全装備解放後は未観測数・照合・達成報酬を案内 |

## 不変条件

観測は一画面。恒常的な説明行や別CTAを追加せず、文言を置き換える。未取得資料の固有名・画像を公開しない。保存互換、ポイント計算、場所に基づく鎮静、自動化非公開、オフライン回復を維持する。会話と恐怖演出はゲーム上の罰を増やさない。

## 検証と限界

一連の「タップ→資料→証言→照合→観測への復帰」、同じ記録の再読・再会・リロード、未取得資料の拒否、侵食後の回復、軽減設定、狭い画面での表示を自動検証する。80通りの観測画面検証も継続する。

「本当に怖いか」「長時間遊んでも飽きないか」はコード検証だけでは解消済みにしない。実プレイで、最初に迷った操作、異変に気づくまでの時間、対処が効いたと理解した瞬間、休みたくなった場面、同じ台詞への飽きを確認する。iPhone実機Safariの操作も未確認なら明記する。
