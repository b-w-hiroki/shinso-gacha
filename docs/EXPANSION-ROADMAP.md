# 真相ガチャ：観測拡張・15の調査ギミック設計

## 今回実装する基盤
- iPhone狭幅でロゴ・残高をグリッド分離し、重なりを抑える。
- 観測の既存4媒体に3つずつ映像状態を付与（計12の表示条件）。同じ画像を使う映像状態であり、場所・異変種の追加ではない。座標/抽選/保存IDは不変。
- メニューから「都市伝説の調査」「図鑑・収集記録」に直接移動。未取得の項目を公開しない。

## 追加企画（15件）の接続先と完成条件
| 企画 | 既存接続先 | Done条件 |
|---|---|---|
| 未来の調査記録 | 受信箱→調査案件 | 未来時刻の架空記録と実際の結果との差異を後日比較 |
| 記録に写る自分 | 観測→図鑑 | ゲーム内職員番号だけを使用、個人情報不使用 |
| 存在しない課員 | 課内の人たち→証言 | 未確認の人物名・立ち絵を未取得時はDOMに出さない |
| 予告された異変 | ガチャ→観測 | 予告は抽選結果を確定させず事後に照合 |
| 変わる調査室 | 調査室 | 調査段階に伴う背景差分、静止・低刺激設定 |
| 隠された関連性 | 図鑑→都市伝説 | 入手した資料だけに関連記号を表示 |
| 不完全な資料 | ガチャ→資料庫 | 断片は別所で取得、重複報酬なし |
| 収集物の再鑑定 | 図鑑 | 新証拠獲得時のみ再鑑定、原本は不変 |
| 異常な重複資料 | 開封→資料 | 原本と比較する演出差分を持つ |
| 秘密の分類 | 図鑑 | 開放条件までは分類名・種類総数を非表示 |
| 誤った真相 | 調査案件 | 結論を消さず再検証・撤回が可能 |
| 証言の信頼性 | 課員→資料 | 事件依存で変化、確定的な「正しい人物」扱いを避ける |
| 複数事件の合同調査 | 調査案件 | 入手済みの2事件だけを関連付け |
| 観測方法による差異 | 観測 | 媒体ごとに記録差分、画像上の接触座標は維持 |
| 調査報告書 | 報告 | 保存済みの仮説・裏付けから再編集可能な報告書を生成 |

## 続く実装フェーズ
1. 実際の新しい観測先の背景・異変差分を媒体別に制作し、各素材をレイヤー分割。既存観測4モードに別の地点を混同させない。
2. 未来の記録/課員/共通記号のデータモデルを導入し、解放・秘匿・保存のテストを作成。
3. 再鑑定・複数事件・報告書を調査ループへ接続。
4. ゲーム内の穏やかな不安の頻度と復帰時の動線を測定し、画面幅320/390/430と844x390でQA。

不変条件：既存ガチャ・報酬・発見済み資料とUID、低刺激設定、未取得資料の秘匿、総収集数の非表示を維持。実機Safari、本番Firebase、長時間プレイ評価は自動ブラウザ試験と別に実施。
