## アプリケーション概要

**ゲーム名**: 真相ガチャ — Unverified Archive
**ジャンル**: 収集型ガチャゲーム（バトルなし・育成なし）
**コンセプト**: ガチャを引くことそのものが目的。集めるコンテンツは「都市伝説」と「陰謀論」。
**トーン**: 皮肉・風刺。重くなりすぎず、でもチープにもならない。オカルト的知性派。

---

## 画面構成（全5画面）

以下の5画面を、タブまたはナビゲーションで切り替えられる形で実装してください。

---

### 画面1: ホーム（メイン画面）

**役割**: ゲームの玄関。通貨残高、放置チャージ状況、クリッカーボタンが一目でわかる。

**表示要素**:
- ゲームタイトル（大）
- 疑念ポイント（通貨）の残高 ← 最も目立つ場所に
- 放置チャージのカウントダウン表示（例：「次の+1まで あと3秒」）
- クリッカーボタン：「真相を嗅ぎ回る」押すたびに+2pt
  - 押した時のフィードバックアニメーション必須
- ガチャボックスへのショートカットカード2枚（都市伝説 / 陰謀論）
- デイリーミッション進捗サマリー（コンパクト、タップでミッション画面へ）

**UXポイント**:
- 通貨残高はリアルタイムで増減する
- クリッカーは「何度押しても飽きない」手触りを意識すること
- 放置チャージ中であることが視覚的にわかる（アニメ or バッジ）

---

### 画面2: ガチャ画面

**役割**: 実際にガチャを引く場所。2つのボックスを切り替えて使う。

**表示要素**:
- ボックス切り替えタブ：「🕯️ 都市伝説」「🔺 陰謀論」
- 選択中ボックスの説明文（1〜2行）
- ガチャボタン：「1回引く（10pt）」「5連（45pt）」
  - 残高不足時はグレーアウト
- ガチャ演出エリア（引いた後に結果カードがフリップ表示される領域）
- 直近の引き結果（3〜5件のログ表示）

**ガチャ結果表示（モーダルまたはインライン）**:
- カード名（Lv0は「???」伏せ字）
- 情報レベルの進捗（1〜5のドット or バー）
- 今回開放されたレイヤーのテキスト（ハイライト表示）
- 「あとN回で全貌が見える」次回煽りテキスト

**UXポイント**:
- 5連引きは1枚ずつ順番に出てくると望ましい
- 新規ネタ初解放 / 重複レイヤー開放 / Lv5到達 の3段階で演出を変える
- 「もう1回引きたくなる」テンポ感を最優先

---

### 画面3: アーカイブ（図鑑）画面

**役割**: 集めたネタの一覧と進捗確認。コレクション欲を刺激する。

**表示要素**:
- ボックス切り替えフィルター（都市伝説 / 陰謀論 / 全て）
- ネタカードのグリッド表示
  - 未発見：カード全体がぼかし or 「???」表示、Lv0/5
  - 発見済み：ネタ名 + Lv進捗バー（1〜5段階の視覚表現）
  - Lv5完了：「真相到達」バッジ or 特別な枠
- 全体の収集進捗（「8/10 ネタ解放 / Lv5達成: 3件」など）
- カードタップで詳細モーダル表示

**詳細モーダル**:
- ネタ名（大）
- カテゴリタグ（都市伝説 / 陰謀論）
- 情報レイヤー一覧（Lv1〜5）
  - 解放済み：テキスト表示
  - 未解放：「── 未解放 ──」グレー表示
- レイヤーラベルの例：
  - Lv1: 噂 / Lv2: 発生時期 / Lv3: 詳細 / Lv4: 信じてる人の特徴（風刺） / Lv5: 真相（風刺オチ）

**UXポイント**:
- 未解放カードの存在が「まだある」という収集欲を煽ること
- Lv4まで開けた状態でLv5だけ「── 未解放 ──」なのが最も効く

---

### 画面4: ミッション画面

**役割**: デイリーミッションで通貨を獲得する。ゲームに戻る動機付け。

**表示要素**:
- 本日のミッション一覧（3〜5件）
  - 各ミッション：達成条件テキスト / 進捗バー or カウント / 報酬pt / 受領ボタン
  - 達成済み+受領済み：ストライクスルー表示
- デイリーリセットまでのカウントダウン
- 「放置ボーナス受け取り」ボタン（オプション）

**ミッション例**:
- 「真相を10回嗅ぎ回る → +15pt」
- 「ガチャを3回引く → +20pt」
- 「新しい情報レイヤーを2つ解放 → +25pt」
- 「陰謀論ボックスを1回引く → +10pt」
- 「アーカイブを開く → +5pt」

**UXポイント**:
- 「達成したから受領する」ではなく「受領したくてミッションをやる」設計に見えること
- 進捗バーが埋まっていく視覚的フィードバックが必要

---

### 画面5: 統計・設定画面

**役割**: ゲームデータの確認 + 軽い設定。

**表示要素**:
- 統計データ
  - 総ガチャ回数
  - 総獲得疑念ポイント
  - 都市伝説 / 陰謀論 それぞれのLv5到達数
  - ゲーム開始日 / 連続ログイン日数
- 軽い風刺テキスト（例：「あなたは真相を XXX 回追い求め、XXX 回真相から遠ざかった」）
- 設定項目
  - サウンド ON/OFF（フラグのみ、実装は後）
  - データリセット（確認ダイアログ付き）

## デザイン仕様

### カラーパレット

```
背景（最深部）: #0a0a0f
背景（カード・パネル）: #14141d
背景（インセット）: #1c1c28
テキスト（メイン）: #d4d4dc
テキスト（サブ）: #6b6b78
アクセント（ゴールド）: #c9a961
アクセント（ダーク）: #8b6f3f
危険・Lv5: #a85050
ボーダー: #2a2a38
```

### レベルカラー（1〜5段階）

```
Lv1: #6b6b78（グレー）
Lv2: #8a9bb0（ブルーグレー）
Lv3: #a89060（ゴールド系）
Lv4: #b8704a（オレンジ系）
Lv5: #a85050（レッド系）
```

### タイポグラフィ

- **見出し**: 明朝体系（"Hiragino Mincho ProN", "Yu Mincho", serif）
- **数値・コード**: monospace（"Courier New"）
- **補助テキスト**: 同じserif系
- letter-spacingを広め（0.1〜0.2em）に取ること

### アニメーション方針

- クリッカーボタン: 押下時に軽くscale(0.97)
- ガチャ演出: カードのフリップ or フェードイン
- 通貨カウンター: 増減時に数値がフラッシュ
- モーダル: フェードイン + 軽い上からスライド

### UIコンポーネント方針

- ボーダーは角丸4px（角ばった印象）
- シャドウよりも発光（box-shadow で色をつける）でレア感を出す
- 「高い」「低い」をスペースの余白量で表現すること

---

## 技術仕様

- **HTML/CSS/JS 単一ファイル**（外部ライブラリなし）
- **localStorage** でゲーム状態を永続化
- **5画面はタブ切り替え**（URLは変えない）
- **放置チャージ**: setInterval で5秒ごとに+1（ページを閉じていた分は次回起動時に計算）
- **デイリーミッション**: 日付が変わったらリセット（0時基準）
- **データ構造のキー**: `shinso_gacha_state_v1`（既存データと互換）

## 優先順位

1. **最優先**: ガチャ画面（引く体験）とアーカイブ画面（コレクション欲）
2. **次**: ホーム画面（クリッカー + 放置）
3. **後回しOK**: ミッション画面、統計画面は骨格のみでよい
