# 調査デスクのUI統一（2026-10-08）

ガチャの写実素材をホーム・資料保管庫・調査室・報告・詳細シート・開封演出へ展開した。

- 暗い調査机、生成済みの資料・カセット・封筒、古紙と金属の色を共通化。追加の画像生成は行っていない。
- 紙のカードを暗い背景で上書きするスタイルを修正。文字と背景の明暗を揃え、未解放資料も全体を半透明にしない。
- ボタンは素材の文字を含まない縁を使用し、ラベルと操作判定はHTMLで維持。
- ホームでも5画面の下部ナビを表示。探知と任務は上部タブに分離。任務画面では無関係な大型CTAを隠す。
- 高さ740px以下のスマホではホームのCTAを文書内に配置し、本文を覆わない。内容が多い画面はスクロールできる。
- 資料詳細の閉じるボタンを44×44pxに拡大。開封演出にも透過封筒を使用し、封を切る操作と資料表示を保持。
- ゲーム・FirebaseのJavaScriptは変更していない。

## 検証

`node tests/smoke.mjs`、`node tests/photoreal.cjs`、`node tests/dossier-ui.cjs`。

既存のガチャ・一括受取・ランク・保存の検証に加え、320/390/1280pxでの各画面の横幅・ナビゲーション、資料絞り込みと詳細、設備強化、再調査、証拠消費、保存・再読み込み、報告シート、疑念pt詳細、封筒演出、初回起動を実ブラウザで確認。公開済みのFirebaseへは書き込まず、既存テストのアダプターで保存境界を検証する。

スクリーンショットはテスト用の進捗で撮影。実ユーザーの保存データではない。実端末Safariでの検証は未実施。

共通スタイルは `assets/dossier-ui.css` に分離。CIでも両ブラウザテストを実行し、検証画像をartifactへ保存する。
