# 真相ガチャ 現行仕様書

**基準：2026-10-11 / main \`41cb70afaf8ef8729cb1e644d3c6cefffce64d2b\`。**
実装の契約を中心に書く。数値や文面は将来変更され得るため、変更時は右記の参照先コードと合わせて更新する。詳細な歴史は \`SPEC.md\` と \`DESIGN.md\`。

## 1. プロダクト

- タイトル：真相ガチャ。架空の第六文書課、都市伝説と陰謀論、官僚的な不穏さを題材にしたスマホ向けブラウザーゲーム。
- ねらい：「何も変わらない日常」→「小さな矛盾を発見」→「見てはいけない情報」→「照合して収集」→「さらに不穏な資料へ」。大きなアクションや戦闘を主軸にしない。
- 入口は非登録の一般人。本人情報・GPSなどの現実データを使って怖がらせない。内部の架空記録で異常を表現する。
- デバイス：スマホ縦画面優先、横画面・PCにも対応。読む詳細画面ではスクロールを許容。常設の情報は最少とする。

## 2. 二つのゲームモードと解放

| 段階 | 主な操作 | 解放・演出 |
| --- | --- | --- |
| 初回・最初の3通 | 封を切る → 駅写真の変化 → 構内図 → 黒塗りのメモ | 1つのCTA。通常ガチャの資料は3断片分進む。比較や再閲覧は無報酬 |
| 一般人編 0〜36断片 | 届く封筒を開く／取得資料を読む | 3断片で「資料」、6断片で「記録」、10断片でフッターメニュー。スキップしただけで機能は解放しない |
| 一般人編 11〜32断片 | 記録の矛盾・異常な通信を確認 | 平穏→不穏→危険→接続危機。過剰説明せず、異変の中身は進行で示す |
| 33〜36断片 | 第六文書課の介入・保護通信・事情聴取 | 33で接続遮断、36で事情聴取と配属。第0章は登録なしでプレイできる |
| 調査員編 | 観測／封筒／資料／調査室／報告・課内会話 | ランク、観測・異変対処・再調査・育成・図鑑・通信が接続する |

参照：\`assets/intro-story.js\`、\`index.html\` の \`litePhase\`、\`updateLiteFooter\`、\`applyMode\`、\`assets/menu.js\`。

## 3. コアループ

\`\`\`text
一般人：封筒 → 資料の断片 → 気づき → 介入／事情聴取
調査員：観測・開封 → 異変／資料獲得 → 記録・証言 → 比較・対処
                   ↘ 疑念pt・証拠 → 装備育成・機密解放 ↗
\`\`\`

- 封筒は都市伝説／陰謀論の二系列。原則5段階（噂→発生時期→詳細→信じる側→真相）で、重複資料は黒塗りを剥がす。真相到達後の再取得から証言、再調査、関連事件へ進む。
- 疑念ptは開封に使う。証拠は調査室の育成と再調査に使う。ほかに侵入案件の対策資料があり、取り違えない。
- 1回10pt、5回45pt、10連90pt（RANK 5）、100連850pt（RANK 11）。5連以上の最低進展、未発見確定の天井を維持する。
- ランクは累計開封回数による20段階（最大30,000回）。ランク補正・深層ファイルと課内機密区分は同じランクを参照し、別XPを増やさない。

参照：\`index.html\` の \`RANK_NEED\`、\`COST\`、\`BULK_RANK\`、\`pull\`、\`claimTruthReward\`。

## 4. 観測と異変

- **4方式**：監視カメラ、公園／写真、食卓／視界ジャック、商店街／車載カメラ、県道。現在は追加の平常背景として地下通路・夜の教室・踏切前・海沿い夜道が表示されることがある。**これは独立した収集IDを備えた追加4地点ではない。**
- 観測画面は大きな映像1枚。平常では映像を触ると照合が進み、保持された結果に従って次へ。異変では画像上の違和感付近への接触だけが対処として有効。
- 異変の基本出現率5%、異常感度の育成で0.5ポイント刻み、最大12%。異変の出現確率と出現後のレアリティ条件付き配分は別。
- 記録保持3時間から最大24時間、巡回効率・間隔・敏感度は段階育成。結果は抽選時に保持し、再ロードや装備変更で引き直さない。
- 自動巡回・自動鎮静は**現行コードで条件付き利用可能**。巡回は記録20件・複数地点、鎮静は手動鎮静10件＋巡回Lv.1が必要。画面が実際に表示中のときだけ動き、バックグラウンド分を一括進行しない。
- 回線切断・休息・課内会話で負荷を下げられる。無操作や離席だけで危険度を上げない。画面周辺への干渉は演出であり実際の保存・操作・報酬を書き換えない。

参照：\`assets/observation-model.js\`、\`assets/observation.js\`。画像の細かなタップ座標・保存移行は \`OBSERVATION.md\`。

## 5. 侵入事件・証言・機密

- 封筒からの侵入事件は固定ID **100種**、レアリティ重み **N/R/SR/SSR = 60/28/10/2**。進行中の事件・種別IDはセーブと図鑑と共有するため、意味を変えず追記する。
- 封筒の調査操作に応じて侵入レベルが上がる。無操作中には増えない。閾値100では新規開封を一時停止し、pt・資料・報酬は奪わない。対処後の保護開封を尊重する。
- 発見／異変位置での接触／回線遮断／証言比較／封印など、種類に応じた手順で明示的に完了する。完了報酬は一度きり。低刺激モードでは刺激表現だけを抑える。
- 課員は白瀬（記録係）、榊（設備担当）、三輪（先輩調査員）。最初の挨拶と話題ごとの返答、会話履歴、回復クールダウンは保存。会話だけで無限回復やポイントを稼がせない。
- 課内地位は RANK 1〜3／4〜6／7〜10／11〜14／15〜17／18〜20 の6区分。上位になるほど記録の矛盾が深まるが、既存の観測抽選を直接増加させない。
- RANK 4/7/11/15/18では三人から人事の矛盾を収集できる。実際に聴いた証言のみ人物図鑑へ出し、三者の照合で一度だけ確定・受信箱へ通知。未入手の証言・結論は表示しない。
- 取得済みの都市伝説事件には、再鑑定、関連する別事件との照合、仮説報告、未登録立会人・未来報告の一部が接続する。未入手の名称・画像はDOMに出さない。
- 未来報告は3断片が揃った案件で明示的に「翌日の照合を依頼」できる。依頼翌日以降に対象方式の観測記録を**実際に回収した場合のみ**、平常／異変の一致・不一致を一度だけ保存する。対象方式以外・当日の観測では完了せず、未来の予告は抽選結果も当たり率も変更しない。完了は受信箱へ一通だけ通知し、取得済み案件へ戻れる。

参照：\`assets/incursions.js\`、\`assets/personnel-discrepancies-model.js\`、\`assets/legend-model.js\`、\`assets/investigation-links.js\`、\`assets/encyclopedia.js\`。

## 7. 保存・アカウント・公開

- 単一HTMLと分割JavaScript/CSSの静的サイト。\`localStorage\` のキーは \`shinso_gacha_state_v1\`。アカウント未登録でも進行できる。
- Firebaseの匿名認証・Google連携・Firestore同期はコードとして存在。競合保存、明示確認、ログアウト、アカウント削除フローは実装。削除済み印で旧セッションからの復活を拒否する設計。
- **本番の認証・権限ルール反映と実アカウント削除は未検証**。Firebaseエミュレーターやテスト用アダプターの成功と区別する。
- GitHub Pages / \`main\` / ルート、独自ドメイン \`shinso-gacha.birdman-studio.com\`。Pagesへの更新とFirebaseルールのデプロイは別工程。
- リアルタイムの社会機能・ランキングは自己申告のクライアント状態であり、ランキングの厳密な不正防止を保証しない。

## 8. 変更してはいけない基本契約

1. 保存済みの事件ID・レベル・証言・育成・所持pt・アカウントデータを失わせない。
2. 未発見の名称・画像・正解・種類総数を事前表示しない。
3. 一般人編の無料・非ログイン入口と36断片からの加入を壊さない。
4. 気づき中心のホラー。コンボ、派手な達成演出、進捗カウンターの常設でジャンルを変えない。
5. フラッシュ・音量・本物の操作妨害を恐怖の代用にしない。縮小動作と演出軽減に対応する。
6. コード上の正常動作と、人間が感じる恐怖・長期の遊びやすさを同一視しない。
