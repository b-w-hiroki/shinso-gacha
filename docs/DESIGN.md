# 設計判断と考慮事項

仕様（何があるか）は `SPEC.md`、本書は「なぜそうしたか」を残す。判断の履歴であり、変更時はここも更新する。

## 1. 原点と中核判断

| 判断 | 理由 | 却下した案 |
|---|---|---|
| ガチャ自体を目的にする | バトルや親愛度は口実になり、引く行為の価値が薄まる | 戦闘・育成の素材としてのガチャ |
| 題材は都市伝説と陰謀論の2箱 | 「集める数」と「知りたくなる情報」の両方を満たす。箱を分けると収集の目標が立つ | 炎上・観光地など（拡張候補としては残す） |
| 1ネタ5段（噂→発生時期→詳細→信じてる人の特徴→真相） | 重複を無駄にせず、引くたびに少し先が見える。「次が気になる」を作る | 重複＝ただの水増し |
| 重複で黒塗りを1段ずつ剥がす | 「未発見」を「???」で隠すより、黒塗りの方が世界観（資料・検閲）と合う | 「???」表示（廃止） |
| トーンは皮肉・風刺 | 信じる人を直接攻撃せず、構造（なぜ広まるか）を風刺する | 煽り・断定 |
| Lv.5（真相）は共有できない | 共有物に含めないことで、見に来る動機を残す。ネタバレの拡散も防ぐ | 全文シェア |

## 2. 排出・経済の設計

- **進捗重み**（未発見×1 / 調査中×1.6 / 真相到達×0.35）：未発見を優先し過ぎると作業感が出るため、調査中を優先して「続きを読む」感覚を作った。シミュレーションで、全収集までの回数が111回から73回に減った
- **レアリティ**（並・稀・禁）と **ランク倍率**：回すほど稀・禁が出やすくなる。ランク1→20で稀×1→1.8、禁×1→2.8
- **天井**：未発見が出ない連続回数が上限（30→15回）に達したら、未発見を確定。さらに設備で最短5回まで短縮できる。12件の箱で、初回の禁は約13回、全発見は約50回、全真相は約83回
- **5連以上の保証**：最低1段は必ず剥がれる。「何も起きない5連」をなくす
- **二重解除**（最大約30%）：当たり感の演出と、終盤の加速
- **20段階ランクと3万回**：上ほど必要回数が約1.46倍ずつ増える。最大は3万回
- **放置**：ランクと設備で加速。留守中は上限付き（2時間＋留守番電話）。無限に貯まるとログインの動機が消える
- **嗅ぎ回り**：日次の軟上限（400pt/800pt）と1秒12回の制限。連打と自動化への対策
- **連続ログイン**：20＋10×日数（最大7日）。前日から連続していなければ1日目に戻るが、既獲得分の減点・没収はない
- **深層ファイル・機密区分外**：ランクと合計段数で解禁。終盤の目標を保つ
- **既知の弱点**：設備が中盤で上限に達し、証拠が余る（SPEC §7）

## 3. 「金の匂い」を避ける

- 「1日1回無料」「本日限定」「お得」などの表現は使わない。無料／有料の対比が、ゲームの皮肉な雰囲気を壊し、課金を連想させるため
- 本日の噂は「本日のウワサを読む」とし、**郵便受けに毎朝何者かが投函する**という演出にした（差出人は不明）
  - 連続日数で文面が変わる（1日目は差出人が空白、7日目以降は「誰かが、こちらを見ている」）
  - 夜間は投函が深夜になる。日替わりの怖い一文が11種ある
  - 読み終えると「差出人は、今日も書かれていない」など、余韻の一文が出る
- 提供割合は、一般公開前に表示ルールを確認する必要がある（SPEC §7）

## 4. 第0章と保護・事情聴取

- **目的**：SNSで広がる説明不要の入口。通貨・放置・ランクを出さず、最初は「封筒を開く」だけで進める
- **感情曲線**：0〜10は平穏、11〜18は不穏、19〜27は危険、28〜32は危機。33で第六文書課が緊急介入し、35で保護通信、36で事情聴取へ進む
- **加入理由**：24断片で自分から応募する旧構造は廃止。見てはいけない領域まで到達して危険に巻き込まれ、第六文書課に救出された結果、一般人のまま放置できないため管理下へ移る
- **事情聴取**：36断片後に3問を行い、回答傾向から調査員タイプと配属を決定する。採用試験ではなく保護手続きの延長として描く
- **意味反転**：序盤の第六文書課は監視者に見えるが、33断片で怪異から守る側だと分かる。本編では「怪異の侵食」から「機密組織の監視・管理」へ恐怖の種類を変える
- **引き継ぎ**：一般人編で読んだ段数は本編の `levels` に反映（上限Lv.3）。観察番号と異常遭遇ログも端末状態に残す
- **既存ユーザー**：ガチャ済み・案内表示済みの既存データは自動で調査員として扱い、追求者番号を後付けしない
- **追求者番号**：機能導入後に新規加入した調査員だけ、加入時の人数を基準に `pursuerNo` を保存する

## 5. 演出と見た目の判断

- **紙の質感**：都市伝説は罫線の聞き取りメモ（手書き風フォント Yomogi）、陰謀論は綴じ穴付きの機密書式。黒塗りは墨スタンプ風のマスク
- **封筒演出**：揺れる→開く→せり上がる→黒塗りが剥がれる。稀は琥珀、禁は赤く脈動。演出が長いと疲れるため、高速モードと、10連以上は演出なしを用意
- **夜間**（22〜5時）：画面が赤みを帯びる。2時台は丑三つ時で、放置が2倍
- **調査スレ**：匿名掲示板風。たまに名前のない書き込みが混ざる。表示は5件
- **`prefers-reduced-motion`** では演出を止める

### 日本語の改行

- `word-break: auto-phrase` と `text-wrap: balance / pretty` を使用
- 非対応ブラウザは BudouX（CDN）、失敗時は簡易の文節分割
- 見出し・短文は文節の途中で折り返さないことを優先する

### 視認性

- 暗い背景に載る黒塗りは、灰色の塗りと明るい縁取りにする（提供割合のモーダル、ロゴ、機密区分外・深層ファイル）
- 紙の上の黒塗りは従来の黒
- 薄い目盛り・罫線は明度を上げる。小さい文字は原則12px前後以上
- **教訓**：`display` を指定した要素は `hidden` 属性に勝つ。全体に `[hidden] { display: none !important; }` を入れた。これが無いと、演出の全画面が起動直後から表示され、操作できなくなる

## 6. 事実確認の方針

- 実在の出来事を扱う陰謀論（電球カルテル、MKウルトラ、エリア51、トンキン湾事件、タバコ業界、鳥は実在しない）は、裏取りしたうえで「事実」判定とする
- 修正した主な点：
  - 電球カルテル：1925年、寿命2,500→1,000時間、罰金、1939年
  - トンキン湾事件：第2の攻撃は無かった。2005年のNSA内部研究で、情報が意図的に歪められていたとされる
  - タバコ業界：1998年の和解、46州、文書公開
  - 鳥は実在しない：2017年に始まり、2021年に創設者が風刺だと認めた
- 陰謀論には必ず「判定」の判子を付ける。引用や切り取りで誤情報として広まるのを防ぐため
- 公開リポジトリのため、Lv.5を含む全文が誰でも読める（許容済み）

## 7. 保存・同期・公開の判断

- **単一HTML＋`localStorage`** から始め、クラウド保存は後付けにした（無くても遊べる）
- **匿名認証＋Google連携**：最初にログインを求めると離脱が増えるため。必要な人だけ連携する
- **競合は `updatedAt` の新しい方を採用**
- **Firestoreのルール**：`users` は本人のみ。`scouts` は読み取りを全員に開き、書き込みは本人かつ項目と上限（`total <= 200`）を検証
- **限界**：状態はクライアント保持のため、改ざんで全解放できる。ランキングの厳密性は担保しない。必要になったらCloud Functionsでの検証を検討する
- **Claude.aiの公開ページは廃止**し、GitHubに一本化。ホストはGitHub Pages＋独自ドメイン（手順は `SETUP.md`）

## 8. 未決・今後の判断

- 提供割合の表示ルールの確定（一般公開前）
- 終盤の経済（証拠の使い道、設備の上限）
- 証言の重複対策（語彙の追加）
- ネタの追加方針（箱ごとに12件を目安、出典リストの整備）
- 一般人モードの計測（どこで離脱するか）。GA4を入れるかは、同意表示とセットで判断

- **日替わり異常**：6断片以降は、その日ごとに全員共通の「本日の異常記録」を1件見られる。日時だけで決まるためサーバー不要で、同日に遊ぶ人が同じ話題を共有できる。

- **スリム化方針**：一般人編で前面に出す操作は「封筒を開く」「観察記録を見る」「調査員になる」の3つまでに抑える。観察番号照合・日替わり異常などは独立ボタンにせず、結果画面や裏側の演出へ畳み込む。節目も3/10/18/24/36断片に整理し、雰囲気を保ちながら操作判断を減らす。

- **スクロール最小化**：スマホでは情報を縦に積み上げず、ボタン切替を優先する。一般人編は「開封 / 資料 / 記録」の3表示に分け、資料内も「都市伝説 / 陰謀論」で切り替える。1画面で次の行動が分かることを優先し、長いスクロールは詳細閲覧時だけに限定する。

- **メイン画面＝イベント受信面**：一般人編の「開封」画面は、封筒・異常・観察記録・面接招待など『今起きていること』を1枚のイベントカードとして表示する。重要イベントをモーダルで連続割り込みさせず、メインに滞留させてプレイヤーが自分のタイミングで読む。イベントが無い時だけ「次の封筒が届いている」を表示する。

- **調査員ホーム＝調査デスク**：本編ホームも一般人編と同じく『今起きていること』を1件だけ中央に出す。優先順位は未読の本日の噂 → 受取可能な任務 → 調査室の強化 → 通常の調査案内。掲示板と任務は「通信 / 任務」に分離し、ホームの縦積みを避ける。

- **残り画面のスリム化**：ガチャは「引く / ランク」、ファイルは「資料 / 証言」、調査室は「強化 / 再調査」、報告は「診断 / 実績 / 設定」に分割し、通常時に長い縦スクロールを要求しない。
- **Lv.5後の再調査**：真相到達を終点にせず、証拠を消費して「異説 → 矛盾 → 裏資料」の3段階を解禁する。3件の再調査を完了すると、単独資料にはない横断照合資料を開示する。
- **週次異常**：一定以上遊んだ調査員には週ごとに共通の異常事件を調査デスクへ1件配信する。日常導線を増やさず、既存のイベント受信面に載せる。

- **第0章の感情曲線**：一般人編は「平穏 → 不穏 → 危険 → 危機 → 救出 → 所属」で進む。0〜10断片は軽い違和感、11〜18断片は監視感、19〜27断片は明確な警告、28〜32断片は接続異常、33断片以降で第六文書課が緊急介入する。
- **組織の意味反転**：第六文書課は序盤では監視者に見えるが、危機発生後に保護側だと分かる。加入は応募ではなく、一般人のまま放置できないための事情聴取・保護手続きとして発生する。
- **視覚的エスカレーション**：一般人編の進行に応じて背景の赤み、イベントカードの警告表現、ノイズを段階的に増やす。33断片以降は逆にノイズを抑え、救出された感覚へ切り替える。

- **危機→救出の視覚反転**：危険域ではイベントカードに監視/接続異常の状態表示、赤系スキャンライン、わずかな文字ズレを加える。33断片以降の救出フェーズではノイズを即座に止め、ヘッダー・イベントカード・フッターを無機質な保護通信トーンへ切り替える。

- **ホラー素材の全面適用**：生成した官僚ホラー素材群の意匠を、開封・資料・記録・危機・救出・着任・調査デスク・追求者ネットワーク・週次異常・通信・調査室へ展開する。一般人編は怪異による侵食、本編は機密組織による監視という異なる怖さにする。状態ラベルは未確認→要確認→監視継続→接続異常→保護通信と変化する。
