# 観測の8地点化・独立収集・異変レイヤー（2026-10-11）

## 実装範囲

- 監視／写真／視界ジャック／車載の4方式は維持し、各方式に**従来地点と追加地点**を設けて計8地点を巡回表示する。方式間の自動巡回・出現率は変えない。
- 追加4地点：地下通路／夜の教室／踏切前／海沿いの夜道。既に登録されている写真調WebPを基準画像として使う。
- 新地点の異変R/SR/SSRに各1枚、計12枚の透過SVGを独立レイヤーで重ねる。元背景を変更せず、画像に文字・操作を焼かない。
- 既存の`WatchModel.TARGETS`と同じ正規化座標に差分の異常物体を置き、異変ごとの接触判定・3×3地域選択・軽減設定・アニメーション禁止を維持する。
- `ObservationSites.register` は `sequence` の偶奇で地点を判定し、`S.observation.siteCollection` に `cctv:alt:1` などを保存。ゲーム経済の既存 `S.observation.collection[mode:rarity]` は変更しない。
- 人物・事件の証拠判定は従来どおり方式単位。追加地点のコレクション報酬、真相判定、異変抽選は増やさない。
- 図鑑「場所」に新地点の名前が現れるのは**その地点の実際の回収記録を得た後**。場所別4レアリティの記録のみ閲覧可能。未発見の資料名はDOMに置かない。
- 旧保存の歴史は媒体単位で取得済みとして保持。過去の観測を勝手に新地点へ振り分けることはしない。新方式で収集した回数のみ地点別の保存対象になる。

## データ設計

- `assets/observation-sites-model.js`：地点と記録のID・表示名・一次資料と背景・重複入力拒否。
- `assets/observation/alt-overlays/{mode}-{1,2,3}.svg`：異常位置と映像上の差分レイヤー12枚。
- `assets/observation.js`：同じ観測映像と接触面のまま追加写真・差分表示、記録回収時に地点別収集情報を追記。
- `assets/encyclopedia.js`：新地点の解放、4状態の台帳と詳細閲覧、元の場所4件を保持。
- 旧セーブの `siteCollection` がない場合は空の追加記録として開始。元の `collection` は常に保存される。

## チューニング・QA

- 8地点の固有ID、8つの平常背景、追加地点に対応する3差分、全形式の画像読み込み、接触座標・再ロード、320×568/390×844/844×390で検証。
- 元写真の解像度は既存の480×240/320×160であり、1440×720の高解像度素材のGitHub取り込みと、同じ構図の高画質異変3段階を作る工程は**未完**。
- 現状の12枚は元写真に重ねるベクター異常表現。写真を編集して作り込んだフォトリアル差分そのものではない。品質レビュー・iPhone実機は別途。
- 観測の媒体は4方式、地点は8か所。この二つをUIで混同しない。抽選と記録の概念も別。

## 残課題

1. 元写真のレタッチ・高解像度差し替え、画像に焼き込まれた文字があれば削除。
2. 新地点のライト/ミドル/ヘビー異常を写真素材ベースの独立画像（今回のレイヤーを土台として）で制作し、比較できるアセット台帳を保存。
3. 旧セーブ時代の媒体別発見数と、今回からの地点別発見数をUI文言で誤認させない。
4. iPhone実機Safariと本番アカウント・Firebaseの検証。
