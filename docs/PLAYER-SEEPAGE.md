# 観測感度の育成とプレイヤー側への干渉

## 確率と育成
|異常感度|費用|平常|R|SR|SSR|異変合計|
|---|---:|---:|---:|---:|---:|---:|
|Lv0|初期|95%|4%|0.9%|0.1%|5%|
|Lv1|200pt|92%|6%|1.7%|0.3%|8%|
|Lv2|500pt|88%|8.5%|2.9%|0.6%|12%|

1タップごとの確率ではなく、巡回完了・定時観測の抽選確率。育成済みレベルと保持中の結果は維持し、新しい抽選から適用する。封筒側100件の希少度配分60/28/10/2は変更しない。

## 染み出す異変：3系統9パターン
- 枠・案内文：閲覧者が一人増える／向こうからも閲覧できる／入退室人数が合わない。周辺枠と画面端の文だけを変更。
- 映り込み：白瀬／榊／三輪の姿が画面の端に一度だけ現れる。1.1秒の低コントラストのフェード。連続点滅や音はない。
- 課員：白瀬が筆跡を先取りする／榊の声が机の下から聞こえる／三輪が背後を見続ける。対応する肖像の色調と会話中の一節を変更。取得資料の証言・人物名・話題の選択肢は保持。

実際の観測・封筒異変が発生し、表示中かつ直近30秒以内に能動的な調査があると、その異変固有の35%判定を一度だけ行う。報酬抽選とは別の決定的な乱数を使用。追加干渉は最長90秒、発生間隔は最低120秒。保存に発生済みキーと映り込み済みフラグを保持し、再描画・再読込で繰り返さない。閉じたモニタの先の課内会話には余韻が残るが、明示的な「回線を切る」または「少し休みたい」で解消する。

控えめ設定では全追加演出を停止。reduced-motionでは映り込みを停止し、会話文と静止した薄い色調のみ。非表示タブ・モーダル・設定画面では描画を止める。不在中に発生させず、復帰時に古い映り込みを再生しない。ボタン位置、タップ判定、実際の残高、保存、報酬には干渉しない。

## 検証
- 10万回×3レベルの固定seed試算、育成費用と保持結果の維持。
- 9パターン、35%判定、保存・再読込、期限・間隔・控えめ・非表示・休息を検証。
- 実入力による発生、1pt加算、3画面サイズ、肖像・会話、操作領域、画面横幅、描画の停止をChromium/WebKitで検証するCIを追加。
- 実機iPhone、人による怖さ・気づきやすさは自動テストでは未確認。
