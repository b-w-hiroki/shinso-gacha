# 低頻度の異変と進行導線

## 変更
- 観測は通常95%、異変5%（R4/SR0.9/SSR0.1）。異常感度Lv1で8%（200pt）、Lv2で12%（500pt）。1タップ1ptは維持。
- 初期の観測先は公園のみ。10タップ（強化で8/6/4）で、解放済みの観測先を順番に巡回する。異変の対処中は巡回しない。
- 食卓は記録5件と100ptで解放。条件成立時は観測画面下に解放導線を表示する。購入後の次の巡回から対象になる。
- 封筒の侵食蓄積は単発12→4、5回開封20→8。初期は単発9回、対処後は休止を含め11回が最短。防護・回復でさらに延びる。
- 発生後の100種抽選はN/R/SR/SSR=60/28/10/2、各段階内で均等、直前の1種を除外。観測記録16件とは別の収集系統。
- 自動巡回は記録20件・観測先2か所、自動対処は手動対処10件・自動巡回Lv1で育成項目を表示。購入までは動作しない。閉じたモニタで自動化は動作しない。
- 封筒の手動対処で同じ記録を得た場合、重複12件から未所持1件を復元できる。復元抽選は未所持から均等。発生中の異変は完了扱いにしない。
- 保管10/25/50/100件で防護素材3/8/15/30を各1回受領できる。記録の証言は担当者の名前・役割・肖像と共に表示。反復で回復を稼げない。
- クラウドは版番号をトランザクションで照合し、古い端末からの上書きを停止する。明示的な読込前に端末記録を退避し、設定からダウンロード可能。

## 検証
モデル・操作テストで巡回、条件解放、手動と自動の得点分離、復元の二重消費防止、証言の冪等性、競合時の退避・復旧を確認。390×680の画面を目視確認。CIにはChromiumに加えWebKitの同じ操作テストを追加。

1000試行のモデル試算（全異変を成功、復元は直ちに利用、強化・放置収入なし）では食卓解放が中央値60タップ、全100件保管が中央値276遭遇。実プレイヤーの所要時間や恐怖の測定ではない。詳細はqa-incursions/incursion-balance.json。

## 外部環境での残検証
- 実機iPhone Safari：アドレスバー開閉、回転、連打、文字拡大、復帰時の余白・重なり・意図しない拡縮。WebKit自動テストは実機検証の代替ではない。
- 人による試遊：初見で対処場所が分かるか、平穏な時間が退屈か不安か、明確な恐怖と静かな違和感の頻度、証言後の再観測導線。
- 広告回復：広告事業者・配信アカウント・広告枠IDが未設定。視聴完了を偽装する報酬は実装しない。接続後、完了・取消・失敗・重複コールバックを検証する。
- 実Firebaseアカウント2端末：同時保存、再認証、オフライン復帰、退避ダウンロードを検証する。今回の自動検証はアダプタによる競合再現。旧バージョンのクライアントは版番号方式を使用しないため、旧版からの書込までサーバールールで強制するものではない。
