## 体験

1. 差出人のない封筒。大きい「封を切る」を押す。
2. 駅の写真を読む。「写真をもう一度見る」で人影が増える。比較ボタンで前後を自由に確認。
3. 2通目の構内図。写真で増えた人物と同じ場所に赤い印。
4. 3通目のメモ。黒塗りを押すと「こちらで、あなたを保護します。／第六文書課」が現れる。
5. 記録を保管し、既存の一般人編へ。後の危険段階・職員介入に伏線をつなぐ。

約60秒は設計上の目安。制限時間や自動送りはなく、読速に合わせて操作できる。文字・時刻・ボタンは画像に焼き込まない。視覚差分には説明文とaltを添え、動きを減らす設定ではアニメーションを使わない。

## 保存と既存機能

- `S.lite.intro` に version/step/revealed/done/completed/skipped を保存。既存の localStorage/Firebase保存境界をそのまま使う。
- 新規の一般人（断片0、導入状態なし）だけ自動開始。途中の一般人・調査員には強制表示しない。
- 封筒3通を開く操作だけ既存 `litePull()` を呼ぶ。通常の抽選プールから各1断片を収集し、開封数は合計3増える。物語の事件記録は通常コレクションとは別に再閲覧できる。
- 比較、黒塗り解除、スキップ、再閲覧に報酬なし。連打防止を設ける。導入中は通常のランダム通知が割り込まない。
- 10/100連、報酬、確率、一般人編36断片、面接解放条件は変更しない。
- `assets/intro-story.js` が物語表示・進行、`assets/intro-story.css` が見た目を担当。

## 文字の視認性

- 紙の上は濃い茶色、暗い面は明るいアイボリーに統一。本文・補足・写真キャプションには不透明な下地を設ける。
- 補足文は14px、主要ボタンのコスト表示も14px。薄い文字・完了項目の透明度・文字を削るマスクを解除。
- 全画面の走査線を除去し、危険演出は文字の背面へ移動。キーボードフォーカスを明示。
- `assets/readability.css` に集約。資料本文・紙上の補足・場面説明・写真キャプション・無効な研究ボタンなど、ブラウザーの計算済み文字色と不透明背景色を測定し4.5:1以上を検査する。写真背景全ピクセルや全状態の適合を保証するものではない。
- 結果: `docs/qa-ui/contrast.json`。変更前後: `docs/qa-ui/readability-comparison.jpg`。
