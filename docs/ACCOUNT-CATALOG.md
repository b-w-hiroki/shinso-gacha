# アカウントと図鑑

## 実装

- メニュー → ログイン・アカウント。ゲスト利用を継続し、既存FirebaseのGoogleプロバイダーを使用する。登録とログインは同じボタン。メール・パスワードの独自保存はしない。
- 匿名アカウントはGoogleにリンクする。既存Googleアカウントへの切替は明示確認し、端末の進行を退避してからリモートを読む。別UIDへの初回読込は常にリモートを優先し、通信失敗後もゲストデータで上書きしない。
- アカウント状態、手動同期、JSON書出し、ログアウトを提供。ログアウトは保存成功後に端末の進行と退避を消す。失敗時はログアウトせずデータを残す。
- 削除は対象を説明し、チェックと確定操作を要求する。Googleユーザーは再認証。保存処理を停止し、進行中の書込を待ってからFirestoreトランザクションで進行を削除済み印に置換し、集計を削除。最後にFirebase Authenticationのユーザーを削除する。
- `users/{uid}` には `{state:{accountDeleted:true},revision:n}` のみ残す。氏名・メール・進行・日時を保持しない。UIDに対応した印は古いセッションからの復活防止のため保持する。削除確認にも明記。Firebase AuthユーザーとGoogleアカウントは別で、Googleアカウントは消さない。
- 削除済み印の更新・削除、同UIDの集計再作成はルールで拒否する。通信失敗・権限不足では成功を表示せず保存を止め、削除再開の導線を残す。
- 複数タブの認証変更を監視。別アカウントへの切替時は旧アカウントの端末状態を破棄してから読む。

## 図鑑

メニューと資料→観測から開く。異変112種（観測12＋封筒100）、人物3名、場所4か所。平常の4記録は場所図鑑の比較資料に含む。

図鑑は既存保存データの表示であり別の発見カウンターを増やさない。異変は入手、人物は面識、場所は記録の回収で開く。未発見の名前・画像はDOMへ出さず、発見済みだけのフィルター、件数、詳細を提供。人物から会話と関連記録、場所から観測記録と入手済みの噂へ進める。閲覧だけではpt・発見・証言の獲得が増えない。

## 公開前の必須作業

**Pagesだけの公開では削除機能は完成しない。** `firebase/firestore.rules` をFirebaseプロジェクト `shinso-gacha` に先に反映する。現環境にはFirebase CLIの認証・Googleサービスアカウントがなく、自動反映は未実施。

Firebase Console → Firestore Database → Rulesでファイル全体を貼って公開、または管理者の認証済み環境で:

```
firebase deploy --only firestore:rules --project shinso-gacha
```

Authenticationの匿名・Googleプロバイダーと公開ホストの承認済みドメインも確認する。その後にクライアントを公開する。
