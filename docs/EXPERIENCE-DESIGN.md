# 体験設計書：異質さ・違和感・継続プレイ

内容照合：2026-10-19 / main `007ba38`。この書は「何を感じさせるか」と画面・演出の判断基準を定める。個別の数値と実際の振る舞いは[現行仕様書](CURRENT-SPEC.md)に従い、更新時は[仕様書と設計書の更新手順](SPEC-DESIGN-WORKFLOW.md)で同じPRの差分を照合する。

## 1. 企画の核

**「確かめることで、知りたくないものに近づく」。**

- 主人公が強くなる＝安全ではない。課内の階級が上がると、より危険な閲覧を許される。
- 観測するほど発見が増える一方、見る行為そのものが見られている感覚へ反転する。
- 自分の意志で封を切る、画像を見比べる、課員に聞く、休む、照合する。選択・気づきが怖さを生む。
- 100枚の刺激的な画像を無造作に並べるより、**同じ空間の平常と異変の差分**を読み取る体験を優先する。

## 2. 感情の曲線

| フェーズ | プレイヤーの認識 | 提示方法 | 禁止・注意 |
| --- | --- | --- | --- |
| 日常 | 封筒が1枚ある | 静かな机、短い見出し、1CTA | 世界観説明・大型メニュー・チュートリアルの羅列 |
| 違和感 | 記録が一致しない | 同時刻なのに人数が変わる、赤い印 | すぐ正解を説明する |
| 不安 | 誰かが見ている | 閲覧履歴、届くはずのない返信 | OSの本物の警告を偽装する |
| 緊張 | 自分の操作が影響する | 画像上の特定位置、抑制、回線遮断 | 強制連打・時間制限・操作妨害 |
| 危機 | 見てはいけないものに近づく | 警告・保存済み記録との矛盾 | 所持品や進行の没収 |
| 反転 | 組織が守っていた | 第六文書課による保護・事情聴取 | 全てを説明して謎を消す |
| 加入 | 組織も不気味 | 同僚の証言相違、人事文書 | 昇進を祝賀エフェクトだけで描く |
| 深層 | 自分が調査対象に | 未来の報告・自分の番号・未登録課員 | 実在する位置・氏名・個人情報の無断利用 |

怖さの尺度はノイズの量ではない。「矛盾を自分で発見したか」「もう一度確認したくなったか」を評価する。

## 3. 1画面1目的

画面名と分類切替は可能なら1段にまとめ、本文を押し下げる重複行を増やさない。分類は44px以上の操作領域を持ち、本文上に固定して重ねない。文字拡大では切り捨てず折り返す。診断にだけ関係する調査員証などの操作は、その本文側に置くが、診断カードと今日の報告より前には出さない。スマホの調査員画面では、共通ヘッダーの飾り情報よりタイトルと所持pt、調査室では説明の常設行より最初の強化対象を優先する。説明は削除せず必要時に開ける。実例と検証範囲は [画面ナビゲーション点検](SCREEN-NAVIGATION-AUDIT-2026-10-19.md)。

メニューの新着は点や裸の数字だけで示さない。「何が」「何件」「なぜ要確認か」が目でも読み上げでも分かる短い語を添える。既読・受取後は古い件数を残さず、一覧へ戻ると再確認できるようにする。

初回：**封筒 / 言葉1行 / 行動1つ**。プレイ中の情報解放は「資料 3断片」「記録 6断片」「メニュー 10断片」。選択できない機能を先に見せて埋め尽くさない。

観測：**大きな映像1枚**。画面下の休息・課内会話・設定は映像と分離。状態説明、再生、観測数、レアリティ、正解座標の常設表示はしない。

観測の上部は視点・地点と必要な画像操作だけに絞る。文字を大きくして横幅に収まらない場合は、地点名を読めないほど削るのではなく行を折り返す。増えた行は映像を覆わず、短い画面で下の操作に届くスクロールを残す。資料や調査室でも、背景写真より文字の判読と押せる範囲を優先する。

資料・人物・場所：既に手に入れたものだけ。名前だけ先出しの図鑑や進捗の総枠を作らない。獲得の喜びは「新しく説明できる矛盾が一つ増えた」で表現。

課内会話：1人の肖像、誰が話しているか、質問、返答、別の話題。小さなテキスト行間を削って詰め込まない。三者照合は明示操作であり、会話を開いただけで報酬にしない。

## 4. ホラーの基本手法（再利用可）

1. **日常の成立**：まず異常のない空間として読み取れること。普通の駅、廊下、食卓、人事台帳。
2. **差分を1点だけ置く**：人数・向き・時刻・位置・声・筆跡・記録上の属性など一つの軸を変更。
3. **気づきを確保**：中央を隠さず、比較ができ、変化が極端に速くならないようにする。
4. **結果を確定しない**：正常と異常のどちらが本当かを早い段階で断言しない。
5. **波及**：一つの証拠が別の証言・資料・場所の読み方を変える。
6. **休息を尊重**：プレイヤーが止めたとき、ゲームが勝手に恐怖ペナルティを蓄積しない。
7. **静かな余韻**：対処後も一つの不一致だけが記録に残る。祝賀・大きなスタンプで終わらせない。

NG例：「突然赤く点滅→危険度+10→報酬+1000」。OK例：「帰投簿に明日の退勤時刻がある。課員に聞くと、誰も当日出勤していないと言う」。

## 5. 課内の昇進は「閲覧権限の深度」

- RANK 1〜3：何かがおかしい。組織の表面にしか触れられない。
- 4〜6：誰が閲覧したか不明のアクセスが残る。
- 7〜10：現地から帰ったはずの人の記録がない。
- 11〜14：職員の証言と日付・勤務表が対立する。
- 15〜17：第六文書課の組織記録自体が変更される。
- 18〜20：調査対象と調査員が入れ替わる。

階級で**異変発生率を一方的に増やすのではなく、遭遇した記録の解釈の深さを変える**。新階級を常設アラートにせず、調査員証・人事通信・事件本文へ分散配置する。

## 6. 繰り返しプレイの価値

| 行動 | すぐ得るもの | 次に期待するもの |
| --- | --- | --- |
| 観測映像に触れる | 平常／異変の発見・控えめなpt | いつもの場所の違い |
| 封筒を開く | 新規・重複・黒塗り段階 | 次に剥がれる断片 |
| 既存資料を見直す | 原本との食い違い | 別解・人間の証言 |
| 課内で話す | 少し落ち着く／証言 | 三人の相互矛盾 |
| 人事照合・再鑑定 | 確定できる記録 | より深い機密・別事件の意味 |
| 席を離れる | 危険度増加なし | 戻った時の「痕跡」 |

単純な数値育成に寄せすぎず、**コレクションが因果関係を持つ**ことを目指す。同じ台詞を繰り返すだけになったら内容を増やすか、頻度・導線を調整する。

## 7. 恐怖演出の安全・アクセシビリティ

- 字形・文字サイズ・コントラストを崩さない。本文に長時間のブラーやグリッチをかけない。
- 点滅や連続フラッシュ、大音量の自動再生、端末権限を詐称する表示をしない。
- 実機GPS・電話帳・カメラ・個人氏名などを取得していないのに取得したかのような不必要に現実的な表示をしない。架空の観測画面であると説明可能にする。
- 演出軽減と \`prefers-reduced-motion\`、キーボード/場所選択の代替操作を維持。
- 失敗・期限切れで所持資料や購入品を没収しない。恐怖と不公平を混同しない。

## 8. レビューでの合否

**自動で検証できること**：初回1CTA、スクロール被りなし、情報秘匿、行動と結果の整合、リロード、位置入力、低刺激設定、ブロッカー無し。

**プレイテストでしか分からないこと**：違和感の発見時間、緊張度、どの行為が怖かったか、理解できた対処、再プレイ意欲、飽き、読み疲れ。指標は「初回3通完遂率」「初異変までの時間」「位置正解率」「資料→証言へ進んだ率」「翌日復帰」を候補とするが**計測実装や実測値は現時点で確認できていない**。

## 9. デザインレビューの短い判断表

- 画面の最初の3秒で主役が何か分かるか。
- セリフを全部消しても、変化の主眼は視覚上読み取れるか。
- その操作が一つ増えることで、本当に新しい遊びが増えたか。
- 発見前の情報が漏れていないか。
- 小さい画面とモーション軽減で同じ結論にたどり着けるか。
- 次に知りたいことを一つ残せたか。


## 2026-10-12：観測者への静かな逆干渉（3種類の追加）

プレイヤーに干渉する演出は、**実在する端末権限を取得したふりをしない架空の資料・声・反射**だけで表現する。

- 過去に存在する9種類の演出・保存済みイベントID 0〜8を維持し、受領印の先行、存在しない席の反射、返答前に出来上がっている課員の書き込みを追加する（ID 9〜11）。
- 過去の遭遇・抽選を引き直さず、出現頻度の全体ゲート35%と90秒持続・120秒クールダウンを維持。新しい3件は新規の実遭遇のみの表現バリエーションであり、ゲーム上の異変当選確率や報酬には一切影響しない。
- quiet/OS reduced-motion、閉じた観測/離席では従来どおり演出を抑える。隠れた画面でイベントを発生させず、本人が休むと停止する。
- 既存のセーブキー、同僚3名・肖像素材、初回獲得済みの発見記録は保持する。評価には実機画面と人間の主観調査が別途必要。


## 2026-10-13：観測視点の識別

- 画面上部に「監視カメラ／写真記録／視界ジャック／車載カメラ」と現在の地点名を二段で常時表示し、観測媒体が直感的に分かるようにする。
- ラベル・拡大・暗部補正は映像外の同一ヘッダーに配置する。映像面積と異変の当たり判定・レアリティ・pt・保存データは不変。
- 320×568、390×844、430×932、844×390では見切れ・ボタン重なりがないこと。未取得の場所名は表示しない。
