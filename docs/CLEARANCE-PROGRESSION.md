# 第六文書課：昇進・機密・危険の段階解放

## 目的
調査員の成長は「安全になること」ではなく「より危険な情報へのアクセス許可」として演出する。第0章の一般人は何も知らずに封筒を開き、第六文書課による救出後、正式に所属する。プレイヤーへの干渉、不安、不信、恐怖、組織の異質さを段階的に深化させる。

## 実装：階級による閲覧区分
| RANK | 課内配置 | 機密区分 | エスカレーション |
| --- | --- | --- | --- |
| 1〜3 | 仮配属 | 一般記録 | 小さな違和感。職員の名前をまだ知らない |
| 4〜6 | 正式調査員 | 指定記録 | 閲覧記録を誰かが見ている |
| 7〜10 | 現地調査班 | 現地機密 | 帰投記録が不整合になる |
| 11〜14 | 特務調査班 | 特別指定 | 証言と勤務表が矛盾する |
| 15〜17 | 機密管理職 | 最上位機密 | 組織の記録そのものが歪む |
| 18〜20 | 深層特務 | 区分外 | 調査員が調査対象に変わる |

- 既存の20段階 RANK は維持。累計開封回数、既存の報酬、排出率、育成上限、セーブ情報を破壊しない。
- 調査員証へ現在の課内配置と閲覧区分、取扱上の警告を追加。進行度メーターや常設アラートは観測ホームへ置かない。
- 選択した当日の事件には処理時のRANKをスナップショット保存する。翌日以降の残留・再発にはその時の階級に応じた不穏な付記が出る。旧セーブで階級情報のない過去事件は最小レベル扱い。
- 付記の追加率は0%、20%、40%、60%、80%、100%。**発生率ではなく、解釈の深刻さ**を変更する。
- 観測異変の基本出現率5〜12%に加算しない。閲覧者の所持pt・資料を没収せず、休息・相談・演出軽減の手段を保持。

## 実装：一般人編の静かな導入
- 冒頭は説明を削り、封筒→写真（人物が増える）→構内図→黒塗りのメモという既存の3通を中心に据える。
- 時刻、言葉、人数の矛盾で緊張を作る。明るい成功演出、進捗ゲージ、詳細なガイド、紙片の受領カウンターを導入中に見せない。
- CTAは1個のみ。導入中はヘッダーの本文と下部ナビを隠し、メニューは設定への最小導線として残す。スキップは初回画面に出さずメニュー内に置く。画面の機能を予告しない。
- 通常モードで3断片を得ると「開封・資料」、6断片で「記録」、10断片で「メニュー」をフッターに解放。スキップしただけでは解放されない。
- 操作や画面を隠す強い点滅・長時間のフラッシュ・偽の端末権限警告は使わない。演出軽減とモバイル可読性を優先する。

## 次の段階で検討する要素
1. 上位階級専用の任務は観測ホームの「処理すべき案件1件」に統合する。
2. 同僚3人の証言の相違、勤務記録と再照合する導線を段階別に追加する。
3. 異変図鑑の上位記録は先に名称・画像を出さず、発見後に再読を促す。
4. 組織内に「管理している者も監視されている」という継続する不安を残す。
5. 高RANKの恐怖密度は上げても、異変の発生頻度だけを引き上げない。
